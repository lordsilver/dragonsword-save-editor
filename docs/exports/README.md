# Export records

The game's art and UI data were exported on the gaming PC by an agent working read-only on the install; the outputs themselves stay outside the repository. These are the records each export wrote, kept so the process can be repeated and checked. [Game assets](../game-assets.md) explains how the editor uses them.

| Folder            | Export                             | What it holds                                                                                                                                                                                                                                                                                                                                                   |
| ----------------- | ---------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `assets/`         | `dsa-assets.zip`, 2026-10-27       | README of the 2D-art export: tools and versions, every step, known issues.                                                                                                                                                                                                                                                                                      |
| `assets-extra/`   | `dsa-assets-extra.zip`, 2026-10-27 | Report on the 18 icon textures the game never shipped, and the game's own fallbacks.                                                                                                                                                                                                                                                                            |
| `skill-ui/`       | `dsa-skill-ui.zip`, 2026-10-27     | README and SUMMARY of the skill-screen export, and its decoded colour, icon and material data. `decoded/DRootIngame.Default__DRootIngame_C.maps.json` is the input `scripts/gen-catalog-extras.mjs` reads.                                                                                                                                                      |
| `skill-slot-fit/` | Claude Opus consult, 2026-10-27    | The prompt, the consult's log and `RESULTS.md` for the fitted skill-slot formula, since replaced by the shader maths (36 discs, mean CIELAB error 7.6 against 20.6 before), and `zones.mjs`, the independent check run afterwards: mean CIELAB of each disc's interior and rim, game against editor.                                                            |
| `xml/`            | `dsa-xml.zip`, 2026-10-30          | README of the XML tables export: every file under the game's `GameData` folder with its folders kept (810), the save schema, how they were read from the paks, and the comparison with the 2026-10-26 extraction. The catalog, rules and texts in `crates/core/data` are generated from these tables.                                                           |
| `skill-shader/`   | `dsa-skill-shader.zip`, 2026-10-27 | SUMMARY and README of the export that disassembled the skill rings' compiled shaders: the per-pixel formula `scripts/gen-icons.mjs` implements, every parameter, the colour path in the exe, and the validation against 30 screenshots; `slots.mjs` is the editor-side check run afterwards (the editor's slots rendered by Chrome, scored on the same pixels). |

The exporter and the scripts each export used are in `tools/asset-export/`.
